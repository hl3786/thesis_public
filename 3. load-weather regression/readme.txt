The file load_weather_regression creates 
a linear regression that matches 
THI to load and applies it to historical 
values, creating resource performance cases. 

notable_weeks.ipynb focuses on the ten highest-
risk weeks in the summer and winter months. 

load_zone_percents allocates the system demand
forecast to all zones. 

metadata_adder.ipynb turns these demand forecasts 
into genx-ready files.
